# Owl Documentation

Owl is an AI agent platform for building intelligent applications.

## Installation

```bash
pip install owl
```

## Usage

```bash
owl train --model mymodel
owl predict --model mymodel
```

## CLI Commands

- `train` - Train a model
- `predict` - Make a prediction
- `evaluate` - Evaluate a model
- `export` - Export a model
- `import` - Import a model
- `list` - List models
- `status` - Show status
- `config` - Show configuration
